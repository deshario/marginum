# Marginum signal analysis

Peak detection in sensor recordings.

- **Main solution:** [`analysis/`](analysis/README.md): Jupyter notebook that counts peaks and
  relates them to tumour size and suctioned volume.
- **Optional:** [`desktop-app/`](desktop-app/README.md): desktop app for opening a signal CSV and
  browsing the detected peaks.

See the README in each folder for setup and how to run it.
